# 🎃 PumpkinEventPlugin 2.0

Хэллоуинский ивент для Paper 1.21.x.

## Новое

- Отдельная **Хэллоуинская тыква** с CustomModelData + PDC. Обычные ванильные тыквы больше не являются валютой.
- Валюта выпадает только с враждебных мобов, убитых игроком; спавнерные мобы по умолчанию исключены.
- Новый GUI на 54 слота с балансом тыкв, осколков и статусом босса.
- **Тыквенный Король** появляется ежедневно, по умолчанию в 20:00 по Москве.
- У босса виртуальный HP, bossbar, фаза с прислужниками, ускорение и ярость.
- Учитывается нанесённый урон. Для награды нужно нанести минимум 2% HP босса.
- Награды поддерживают консольные команды, например `setbal %player% 50`.
- За победу выдаётся **Осколок Короны**.
- За 1000 тыкв + 10 осколков покупается **Фонарь Тыквенного Короля**.
- Фонарь даёт Night Vision во второй руке; ПКМ подсвечивает и замедляет ближайших монстров.

## Настройка босса

Встаньте на арене и выполните:

```
/pumpkin boss setspawn
```

Проверка вручную:

```
/pumpkin boss start
/pumpkin boss stop
```

Статус для игроков:

```
/pumpkin boss
```

Время, HP, награды, порог участия и все основные параметры находятся в `config.yml`.

## CustomModelData

- 10001 — Хэллоуинская тыква
- 10002 — Осколок Короны
- 10003 — Фонарь Тыквенного Короля

Сами текстуры/модели в репозиторий не добавлены. Эти ID нужно связать с вашим resource pack/Oraxen.

## Награды босса

Команды выполняются от консоли:

```yaml
boss:
  rewards:
    participation:
      commands:
        - "setbal %player% 50"
    top-damage:
      1:
        commands:
          - "setbal %player% 100"
```

Placeholder'ы: `%player%`, `%damage%`.
